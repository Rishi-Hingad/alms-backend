Remittance Tool - Developer Documentation

Generated on 2026-02-04

Overview

Remittance Tool is a Frappe module for capturing outbound remittance data, including company/vendor master data, tax details, and invoice and tax-document line items. The central transaction doctype is Remittance with two child tables: Remittance Invoice and Remittance Tax Document.

Masters

  • Remittance Nature
  • Remittance Bank Branch
  • Remittance Tax Document Type

Child Tables

  • Remittance Invoice (child of Remittance)
  • Remittance Tax Document (child of Remittance)

Remittance: Field Highlights

  • Core references: company, vendor, country_of_residence, country_to_remit, currency
  • Amounts: amount_payable_foreign/inr, exchange_rate, gross/net/tds fields
  • Tax details: tds_rate_income_tax_act, tds_rate_dtaa, gross_up, trc_obtained, dtaa fields
  • SAP references: sap_company_code, sap_document_no, sap_invoice_no, document_date
  • Child tables: invoices, tax_documents

APIs

Master Data API

File: remittance_tool/api/master.py

  • get_master_data(doctype, fields=None, filters=None, limit=200)
    • Only allows doctypes in ALLOWED_MASTER_DOCTYPES.
    • Returns data via frappe.get_all.
  • upsert_master_data(doctype, data)
    • Creates or updates master data. Accepts JSON string or dict.
    • If name exists, it updates the document, else inserts a new one.

SAP Integration API

File: remittance_tool/api/sap.py

  • create_remittance_from_sap(payload)
    • Creates a Remittance document from an external payload.
    • Copies top-level fields directly to Remittance.
    • Appends invoices and tax_documents arrays to child tables.
    • Returns the created Remittance name.

UI Customizations (JS)

Each doctype now has a matching .js file for UI customizations. Current files include: remittance.js, remittance_company.js, remittance_vendor.js, remittance_bank_branch.js, remittance_currency.js, remittance_country.js, remittance_nature.js, remittance_purpose_code.js, remittance_tax_document_type.js, remittance_tax_document.js, remittance_invoice.js.

These files currently include a minimal refresh hook as a placeholder for future UI logic (hide/show fields, custom buttons, client-side validation, etc.).

Permissions

Remittance doctype grants create/read/write/delete/report/print/email/export permissions to the System Manager role. (Other doctypes inherit default permissions. Review or extend permissions as needed.)

Typical Workflow (Developer View)

  1. Create or import master data (Company, Vendor, Country, Currency, etc.).
  2. Create a Remittance record from UI or SAP API.
  3. Populate invoices and tax documents child tables.
  4. Compute tax/amount details via custom logic (server/client, as needed).

Notes for Extension

  • Server logic: add validations or calculations in respective doctype/*.py files.
  • Client logic: add UI rules in doctype/*.js files.
  • API: use frappe.whitelist() methods in api/ for integrations.
